# Changelog

All notable changes to Parley are recorded here. Newest first.
Format loosely follows [Keep a Changelog](https://keepachangelog.com); dates are release/submission dates.

## [0.3.1] — build 20

The 0.3.x cycle is a major reliability and performance pass over the recording →
transcription → summarization pipeline, plus a typographic refresh of the library.
Everything still runs 100% on-device; nothing is uploaded.

### Performance
- **Transcription is dramatically faster.** Rewrote it from one Whisper call per
  diarized speaker turn to a single **windowed pass** over the audio. The old approach
  paid a fixed ~5 s of per-call overhead on every segment (hundreds of calls on a long
  meeting); the new approach pays it a handful of times. Hour-long recordings now
  transcribe in minutes instead of 8–10+.
- **Summarization no longer overloads Apple Intelligence.** The per-chunk sub-passes
  (summary, topics) now run sequentially and paced instead of firing concurrently, which
  was tripping the on-device model's rate limiter on long meetings.

### Reliability
- **Long meetings reliably summarize.** Fixed the rate-limit cascade that caused
  hour-long meetings to fail summarization entirely.
- **Summaries no longer come back empty.** When the final "polish" reduce step fails, the
  summary now falls back to the per-chunk summaries already generated, instead of blanking.
- **Transcripts are never discarded.** If summarization is interrupted, the recording is
  still saved with its transcript, and a **Generate summary** retry appears in the detail
  view (re-runs on the saved transcript — no re-transcription).
- **Smarter retries.** Apple Intelligence content-safety refusals are no longer retried
  (they're deterministic); rate-limit errors now back off properly.
- **Fixed a transcription timeout.** Resolved a CoreML "ML Program prediction timeout" on
  long audio by transcribing in bounded windows with a brief rest and a one-shot retry
  per window.
- **Cleaner transcript text.** Stripped Whisper special/timestamp tokens
  (e.g. `<|startoftranscript|>`, `<|0.00|>`) from the displayed transcript.

### Content
- Output focused on **Title, Summary, Topics, and Transcript.** Action items were removed
  — a third fewer on-device model calls per chunk and one less failure mode. (Attendees,
  Decisions, Open Questions, and Key Dates were also removed earlier in the cycle for
  signal/reliability reasons.)
- Topics are fuzzy-deduplicated and capped.

### Design
- **Library list typography refresh.** One consistent vertical rhythm and leading;
  hierarchy carried by tone (title → summary → metadata) rather than weight; section
  labels optically centered on their cap-height; a single unified metadata line
  (duration · speakers) with tabular figures; and a clean right-hand date column with the
  disclosure chevron removed.

### Build / project
- Build number is sourced solely from `project.yml` (both the app and the Live Activity
  extension targets) and bumped to **20**. Always bump it there — the Info.plists are
  generated by XcodeGen, so edits made in Xcode are overwritten on the next
  `xcodegen generate`.

## [0.1.x] — App Store

Initial public releases: on-device recording, diarized transcription (WhisperKit +
SpeakerKit), Apple Foundation Models summarization, AES-256-GCM encryption at rest,
Face ID gate, Live Activity, and the Braun/Dieter Rams-inspired interface.
